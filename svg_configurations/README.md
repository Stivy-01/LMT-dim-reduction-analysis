# Mouse configurations

One standalone SVG per configuration of the source figure.
Every file contains only the mouse drawing (strokes and the
dashed social-range circles), with a transparent background and
no caption text. Colour is `currentColor`, so the artwork takes
the colour of the figure it is placed in (black by default).

Open `index.html` for a visual index.
