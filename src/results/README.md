# Analysis result tables (`src/results`)

Result tables from the final thesis run that no figure script reads.
They are kept as record; figure inputs live in `src/visualization/data/`.

- `bootstrap_permutation.csv` — cage-level change-in-change estimates.
- `date_corrections_applied.csv` — applied manual date corrections.
- `genotype_*_signflip_pvalues.csv` — raw genotype sign-flip p-values
  (the `paper_*` versions used by figures live in `visualization/data/`).
- `pca_scores.csv` — per-row PCA scores (loadings used by figures are in
  `visualization/data/`).
- `thesis_analysis_report.html` — run report.
